Fitur & Elemen HTML yang Digunakan
Tabel: Menggunakan <table>, <thead>, <tbody>, <tfoot>, serta colspan untuk menyusun data nilai dan profil mahasiswa.   
JPG

Form & Validasi: Menggunakan <form>, <input>, <textarea>, <select>, serta atribut validasi seperti required, min, max, dan minlength.   
JPG

Semantic HTML: Menggunakan tag <header>, <nav>, <main>, <section>, <article>, <aside>, dan <footer> agar struktur halaman lebih rapi.   
JPG

Media: Menyematkan elemen <audio> dan <video> untuk pemutaran file media.
